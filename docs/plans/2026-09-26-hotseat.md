# HotSeat Implementation Plan

> Built by **Ember Syndicate**. Steps use checkbox (`- [ ]`) syntax for tracking. Changes are logged in `CHANGELOG.md` (no commits during the build).

**Goal:** A web app where a student uploads their resume, gets grilled claim-by-claim by Gemini (shaped by past candidates' real interview reports for a chosen company), and receives a defensibility heatmap with fix plans.

**Architecture:** Static React SPA, no server. Gemini is called through Firebase AI Logic (Gemini Developer API, Spark plan), so no API key ships to the browser. All session logic is a pure reducer; the AI layer is an interface with a Firebase adapter, so tests never touch the network. Company profiles are distilled once, locally, by a Python script into `src/data/companies.json`.

**Tech Stack:** Vite 8, React 19, TypeScript 6 (strict), Zod 4, firebase 12.19 (`firebase/ai`), Vitest 5 + Testing Library + jsdom, ESLint 10 (flat config), Python 3 stdlib (data script), Firebase Hosting.

**Spec:** `docs/specs/2026-09-26-hotseat-design.md`

## Global Constraints

- The source project's name must never appear anywhere in this repo. Product name: **HotSeat**, tagline *Can you defend your resume?*
- No personal data (student names, roll numbers, emails, phone numbers) in any committed file.
- No secrets committed: `.env*` is gitignored except `.env.example`.
- Model: `gemini-3.8-flash`, overridable by `VITE_GEMINI_MODEL`; JSON output via `responseJsonSchema`; `thinkingLevel: LOW`.
- Answer length ≤ 1500 chars; resume PDF ≤ 10 MB and must start with `%PDF-`.
- Max 3 questions per claim; 5–8 claims extracted; AI calls rate-limited to 12/min per tab.
- Verdicts are never colour-only: icon + text label + colour.
- Single git branch `main`; repo < 10 MB.
- Every command runs from `D:\Hackathon\GDG\hotseat`.

`scripts/distill_companies.py`
```python
"""Distil past candidates' placement feedback into anonymised company interview profiles.

One-time, local-only pipeline. Reads text chunks (already extracted from the past candidates'
feedback PDFs) from a Chroma SQLite file, redacts personal data, asks Gemini to summarise
each company's interview process, scrubs the output again, and writes
src/data/companies.json. Source documents never enter this repository.

Usage:
    python scripts/distill_companies.py --db PATH/chroma.sqlite3 [--limit 60] [--workers 3]

Needs GEMINI_API_KEY in the environment or in .env.local.
"""
from __future__ import annotations

import argparse
import concurrent.futures as cf
import json
import os
import re
import sqlite3
import sys
import time
import urllib.error
import urllib.request
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
OUT_PATH = ROOT / "src" / "data" / "companies.json"
MODEL = os.environ.get("DISTILL_MODEL", "gemini-3.8-flash")
API_URL = f"https://generativelanguage.googleapis.com/v1beta/models/{MODEL}:generateContent"
MAX_CHARS_PER_COMPANY = 60_000
CONTENT_KEYS = ("roles", "rounds", "techTopics", "sampleQuestions", "hrQuestions", "tips")

STUDENT_BLOCK = re.compile(r"(?<!COMPANY )\bNAME\s*:.{0,400}?(?=COMPANY\s*NAME\s*:)", re.I | re.S)
NAME_FIELD = re.compile(
    r"(?<!COMPANY )\bNAME\s*:\s*([A-Za-z][A-Za-z .]{1,60}?)(?=\s+(?:ROLL|REG|DEPARTMENT|EMAIL|CONTACT)|$)", re.I
)
LABELLED_ID = re.compile(
    r"\b(?:ROLL\s*(?:NO|NUMBER)?|REG(?:ISTER)?\s*(?:NO|NUMBER)|EMAIL\s*(?:ID)?|CONTACT\s*(?:NO|NUMBER)"
    r"|MOBILE(?:\s*NO)?|PHONE)\s*[:\-]\s*\S+",
    re.I,
)
EMAIL = re.compile(r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+")
PHONE = re.compile(r"(?<!\d)(?:\+?91[\s-]?)?[6-9]\d{4}[\s-]?\d{5}(?!\d)")
LONG_NUMBER = re.compile(r"\b\d{7,}\b")

PROFILE_SCHEMA = {
    "type": "object",
    "properties": {
        "roles": {"type": "array", "items": {"type": "string"}, "maxItems": 4},
        "rounds": {
            "type": "array",
            "maxItems": 6,
            "items": {
                "type": "object",
                "properties": {
                    "name": {"type": "string"},
                    "format": {"type": "string"},
                    "focus": {"type": "array", "items": {"type": "string"}, "maxItems": 6},
                },
                "required": ["name", "format", "focus"],
            },
        },
        "techTopics": {"type": "array", "items": {"type": "string"}, "maxItems": 12},
        "sampleQuestions": {"type": "array", "items": {"type": "string"}, "maxItems": 12},
        "hrQuestions": {"type": "array", "items": {"type": "string"}, "maxItems": 6},
        "tips": {"type": "array", "items": {"type": "string"}, "maxItems": 6},
    },
    "required": list(CONTENT_KEYS),
}

PROMPT = """You are summarising placement feedback written by engineering students after interviews at {company}.
Produce a factual interview profile of {company} for juniors preparing for it.
Rules:
- Use only information present in the feedback below. Do not invent anything.
- NEVER include any person's name, roll number, email, phone number or other personal detail.
- sampleQuestions: real questions students reported being asked, rewritten as clean standalone questions.
- Keep every string under 160 characters.

<feedback>
{text}
</feedback>"""


def slugify(name: str) -> str:
    return re.sub(r"[^a-z0-9]+", "-", name.lower()).strip("-")


def student_names(text: str) -> set[str]:
    """Name tokens (3+ letters) from NAME fields, used to scrub the model output."""
    names: set[str] = set()
    for match in NAME_FIELD.finditer(text):
        names.update(t.lower() for t in re.split(r"[\s.]+", match.group(1)) if len(t) >= 3)
    return names


def redact(text: str) -> str:
    text = STUDENT_BLOCK.sub("[student details removed] ", text)
    text = LABELLED_ID.sub("[removed]", text)
    text = EMAIL.sub("[email]", text)
    text = PHONE.sub("[phone]", text)
    return LONG_NUMBER.sub("[number]", text)


def contains_pii(value: str, names: set[str]) -> bool:
    if EMAIL.search(value) or PHONE.search(value) or LONG_NUMBER.search(value):
        return True
    return bool({w.lower() for w in re.findall(r"[A-Za-z]+", value)} & names)


def scrub(profile: dict, names: set[str]) -> dict:
    """Drop any string (or list item) that still looks like personal data."""
    clean: dict = {}
    for key, value in profile.items():
        if isinstance(value, str):
            clean[key] = "" if contains_pii(value, names) else value
        elif isinstance(value, list):
            clean[key] = [
                scrub(item, names) if isinstance(item, dict) else item
                for item in value
                if isinstance(item, dict) or (isinstance(item, str) and not contains_pii(item, names))
            ]
        else:
            clean[key] = value
    return clean


def load_api_key() -> str:
    key = os.environ.get("GEMINI_API_KEY", "")
    env_file = ROOT / ".env.local"
    if not key and env_file.exists():
        for line in env_file.read_text(encoding="utf-8").splitlines():
            if line.startswith("GEMINI_API_KEY="):
                key = line.split("=", 1)[1].strip().strip('"')
    if not key:
        sys.exit("GEMINI_API_KEY is not set (environment or .env.local).")
    return key


def load_chunks(db_path: Path) -> dict[str, list[tuple[str, str]]]:
    """company -> [(source file, text)] for PDF sources, in insertion order."""
    con = sqlite3.connect(db_path)
    rows = con.execute(
        """SELECT MAX(CASE WHEN m.key = 'company' THEN m.string_value END),
                  MAX(CASE WHEN m.key = 'source' THEN m.string_value END),
                  MAX(CASE WHEN m.key = 'chroma:document' THEN m.string_value END)
           FROM embeddings e JOIN embedding_metadata m ON m.id = e.id
           GROUP BY e.id ORDER BY e.id"""
    ).fetchall()
    con.close()
    grouped: dict[str, list[tuple[str, str]]] = {}
    for company, source, text in rows:
        if company and text and (source or "").lower().endswith(".pdf"):
            grouped.setdefault(company.strip(), []).append((source, text))
    return grouped


def call_gemini(api_key: str, company: str, text: str) -> dict:
    body = {
        "contents": [{"parts": [{"text": PROMPT.format(company=company, text=text)}]}],
        "generationConfig": {
            "responseMimeType": "application/json",
            "responseJsonSchema": PROFILE_SCHEMA,
            "thinkingConfig": {"thinkingLevel": "low"},
        },
    }
    request = urllib.request.Request(
        API_URL,
        data=json.dumps(body).encode("utf-8"),
        headers={"Content-Type": "application/json", "x-goog-api-key": api_key},
        method="POST",
    )
    for attempt in range(6):
        try:
            with urllib.request.urlopen(request, timeout=180) as response:
                payload = json.load(response)
            parts = payload["candidates"][0]["content"]["parts"]
            return json.loads("".join(p.get("text", "") for p in parts if not p.get("thought")))
        except urllib.error.HTTPError as error:
            if error.code in (429, 500, 503) and attempt < 5:
                time.sleep(min(60, 5 * 2**attempt))
                continue
            raise
    raise RuntimeError("retries exhausted")


def build_profile(api_key: str, company: str, chunks: list[tuple[str, str]]) -> dict | None:
    raw = "\n".join(text for _, text in chunks)
    profile = scrub(call_gemini(api_key, company, redact(raw)[:MAX_CHARS_PER_COMPANY]), student_names(raw))
    if not profile.get("sampleQuestions") and not profile.get("techTopics"):
        return None
    return {
        "id": slugify(company),
        "name": company,
        "reports": len({source for source, _ in chunks}),
        **{key: profile.get(key, []) for key in CONTENT_KEYS},
    }


def write_profiles(profiles: dict[str, dict]) -> None:
    ordered = sorted(profiles.values(), key=lambda p: p["name"].lower())
    OUT_PATH.write_text(json.dumps(ordered, indent=1, ensure_ascii=False) + "\n", encoding="utf-8")


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--db", required=True, type=Path)
    parser.add_argument("--limit", type=int, default=60)
    parser.add_argument("--workers", type=int, default=3)
    args = parser.parse_args()

    api_key = load_api_key()
    grouped = load_chunks(args.db)
    existing = json.loads(OUT_PATH.read_text(encoding="utf-8")) if OUT_PATH.exists() else []
    profiles = {p["id"]: p for p in existing}
    todo = [
        (company, chunks)
        for company, chunks in sorted(grouped.items(), key=lambda kv: -len(kv[1]))[: args.limit]
        if slugify(company) not in profiles
    ]
    print(f"{len(todo)} companies to distil ({len(profiles)} already done)")
    with cf.ThreadPoolExecutor(max_workers=args.workers) as pool:
        futures = {pool.submit(build_profile, api_key, company, chunks): company for company, chunks in todo}
        for future in cf.as_completed(futures):
            company = futures[future]
            try:
                profile = future.result()
            except Exception as error:  # keep going; one bad company must not stop the run
                print(f"  ! {company}: {error}")
                continue
            if profile:
```

`src/domain/session.ts`
```ts
import type { Assessment, Claim, ClaimResult, ClaimState, FixPlan, TestedVerdict } from './model';

export const MAX_TURNS_PER_CLAIM = 3;

export type Phase = 'start' | 'extracting' | 'interview' | 'results';

export interface SessionState {
  phase: Phase;
  companyId: string;
  claims: ClaimState[];
  /** Index of the claim being defended, or -1 when none is active. */
  activeIndex: number;
  currentQuestion: string;
  /** True while re-defending one claim from the results screen. */
  singleClaim: boolean;
  error: string;
}

export type SessionAction =
  | { type: 'extractStarted'; companyId: string }
  | { type: 'claimsExtracted'; claims: Claim[] }
  | { type: 'answerAssessed'; answer: string; assessment: Assessment }
  | { type: 'finishNow' }
  | { type: 'redefendStarted'; claimId: string }
  | { type: 'fixPlanLoaded'; claimId: string; fixPlan: FixPlan }
  | { type: 'failed'; message: string }
  | { type: 'reset' };

export const initialSession: SessionState = {
  phase: 'start',
  companyId: 'general',
  claims: [],
  activeIndex: -1,
  currentQuestion: '',
  singleClaim: false,
  error: '',
};

const untested = (): ClaimResult => ({ verdict: 'untested', depthReached: 0, evidence: '', gap: '' });

export function sessionReducer(state: SessionState, action: SessionAction): SessionState {
  switch (action.type) {
    case 'extractStarted':
      return { ...initialSession, phase: 'extracting', companyId: action.companyId };
    case 'claimsExtracted':
      if (action.claims.length === 0) {
        return { ...state, phase: 'start', error: 'No resume claims found in that file. Please upload your resume PDF.' };
      }
      return {
        ...state,
        phase: 'interview',
        claims: action.claims.map((claim) => ({ claim, turns: [], result: untested() })),
        activeIndex: 0,
        currentQuestion: action.claims[0].openingQuestion,
        singleClaim: false,
        error: '',
      };
    case 'answerAssessed':
      return applyAssessment(state, action.answer, action.assessment);
    case 'finishNow':
      return toResults(state);
    case 'redefendStarted': {
      const index = state.claims.findIndex((c) => c.claim.id === action.claimId);
      if (index < 0) return state;
      const claims = state.claims.map((c, i) => (i === index ? { claim: c.claim, turns: [], result: untested() } : c));
      return {
        ...state,
        phase: 'interview',
        claims,
        activeIndex: index,
        currentQuestion: claims[index].claim.openingQuestion,
        singleClaim: true,
        error: '',
      };
    }
    case 'fixPlanLoaded':
      return {
        ...state,
        error: '',
        claims: state.claims.map((c) => (c.claim.id === action.claimId ? { ...c, fixPlan: action.fixPlan } : c)),
      };
    case 'failed':
      return { ...state, phase: state.phase === 'extracting' ? 'start' : state.phase, error: action.message };
    case 'reset':
      return initialSession;
  }
}

function applyAssessment(state: SessionState, answer: string, assessment: Assessment): SessionState {
  const active = state.claims[state.activeIndex];
  if (!active) return state;
  const turns = [...active.turns, { question: state.currentQuestion, answer }];
  const { verdict, depthReached, evidence, gap } = assessment;
  const claims = state.claims.map((c, i) =>
    i === state.activeIndex ? { ...c, turns, result: { verdict, depthReached, evidence, gap } } : c,
  );
  const probe =
    assessment.decision === 'probe' && assessment.nextQuestion.trim() !== '' && turns.length < MAX_TURNS_PER_CLAIM;
  if (probe) return { ...state, claims, currentQuestion: assessment.nextQuestion, error: '' };
  const next = state.activeIndex + 1;
  if (!state.singleClaim && next < claims.length) {
    return { ...state, claims, activeIndex: next, currentQuestion: claims[next].claim.openingQuestion, error: '' };
  }
  return toResults({ ...state, claims });
}

function toResults(state: SessionState): SessionState {
  return { ...state, phase: 'results', activeIndex: -1, currentQuestion: '', singleClaim: false, error: '' };
}

const VERDICT_POINTS: Record<TestedVerdict, number> = { defended: 100, shaky: 50, exposed: 0 };

/** Average over tested claims (defended 100, shaky 50, exposed 0); null when nothing was tested. */
export function defensibilityScore(claims: ClaimState[]): number | null {
  const tested = claims.flatMap(({ result }) => (result.verdict === 'untested' ? [] : [result.verdict]));
  if (tested.length === 0) return null;
  return Math.round(tested.reduce((sum, verdict) => sum + VERDICT_POINTS[verdict], 0) / tested.length);
}
```

```ts
import { initialSession, type Phase, type SessionState } from './session';

const KEY = 'hotseat.session.v1';
const PHASES: readonly Phase[] = ['start', 'extracting', 'interview', 'results'];

/** Restores the saved session from this browser only; anything unreadable starts fresh. */
export function loadSession(storage: Storage = localStorage): SessionState {
  try {
    const raw = storage.getItem(KEY);
    if (!raw) return initialSession;
    const saved = JSON.parse(raw) as SessionState;
    if (!PHASES.includes(saved.phase) || !Array.isArray(saved.claims)) return initialSession;
    return saved.phase === 'extracting' ? { ...saved, phase: 'start' } : saved;
  } catch {
    return initialSession;
  }
}

export function saveSession(state: SessionState, storage: Storage = localStorage): void {
  try {
    storage.setItem(KEY, JSON.stringify(state));
  } catch {
    // Storage full or blocked: the session simply won't survive a reload.
  }
}

export function clearSession(storage: Storage = localStorage): void {
  try {
    storage.removeItem(KEY);
  } catch {
    // Nothing stored or storage blocked: nothing to clear.
  }
}
```

```ts
/** An error whose message is safe and helpful to show to the student. */
export class UserFacingError extends Error {}

export function friendlyError(error: unknown): string {
  if (error instanceof UserFacingError) return error.message;
  const message = error instanceof Error ? error.message : String(error);
  if (/quota|429|exhausted|rate/i.test(message)) return 'The AI is busy right now. Wait a few seconds and try again.';
  if (/network|fetch|offline/i.test(message)) return 'Network problem. Check your connection and try again.';
  return 'Something went wrong while talking to the AI. Please try again.';
}
```

`src/lib/rateLimiter.ts`
```ts
export interface RateLimiter {
  tryAcquire(): boolean;
  retryAfterMs(): number;
}

/** Sliding-window limiter: at most `max` calls in any `windowMs` period. */
export function createRateLimiter(max: number, windowMs: number, now: () => number = Date.now): RateLimiter {
  const calls: number[] = [];
  const prune = () => {
    const cutoff = now() - windowMs;
    while (calls.length > 0 && calls[0] <= cutoff) calls.shift();
  };
  return {
    tryAcquire() {
      prune();
      if (calls.length >= max) return false;
      calls.push(now());
      return true;
    },
    retryAfterMs() {
      prune();
      return calls.length < max || calls.length === 0 ? 0 : calls[0] + windowMs - now();
    },
  };
}
```

```ts
const KEPT_KEYWORDS = new Set(['type', 'properties', 'required', 'items', 'enum', 'minimum', 'maximum', 'minItems', 'maxItems']);

/** Converts a Zod schema to the JSON Schema subset used for Gemini structured output. */
export function toGeminiJsonSchema(schema: z.ZodType): Record<string, unknown> {
  return prune(z.toJSONSchema(schema)) as Record<string, unknown>;
}

function prune(node: unknown): unknown {
  if (Array.isArray(node)) return node.map(prune);
  if (node === null || typeof node !== 'object') return node;
  const out: Record<string, unknown> = {};
  for (const [key, value] of Object.entries(node)) {
    if (key === 'properties') {
      out.properties = Object.fromEntries(
        Object.entries(value as Record<string, unknown>).map(([name, child]) => [name, prune(child)]),
      );
    } else if (KEPT_KEYWORDS.has(key)) {
      out[key] = prune(value);
    }
  }
  return out;
}
```

```ts
import type { z } from 'zod';
import type { CompanyProfile } from '../data/companies';
import {
  assessmentSchema,
  extractionSchema,
  fixPlanSchema,
  type Assessment,
  type Claim,
  type ClaimResult,
  type FixPlan,
  type Turn,
} from '../domain/model';
import { UserFacingError } from '../lib/errors';
import type { RateLimiter } from '../lib/rateLimiter';
import { toGeminiJsonSchema } from './jsonSchema';
import { assessPrompt, extractClaimsPrompt, fixPlanPrompt } from './prompts';

export interface GenerateRequest {
  prompt: string;
  pdfBase64?: string;
  responseJsonSchema: Record<string, unknown>;
}

/** Sends one prompt to the model and resolves with its raw text response. */
export type GenerateText = (request: GenerateRequest) => Promise<string>;

export interface AiClient {
  extractClaims(pdfBase64: string, company: CompanyProfile | null): Promise<Claim[]>;
  assess(claim: Claim, turns: Turn[], company: CompanyProfile | null): Promise<Assessment>;
  fixPlan(claim: Claim, result: ClaimResult, company: CompanyProfile | null): Promise<FixPlan>;
}

const MAX_ATTEMPTS = 2;

export function createAiClient(generate: GenerateText, limiter: RateLimiter): AiClient {
  async function ask<T>(schema: z.ZodType<T>, prompt: string, pdfBase64?: string): Promise<T> {
    const responseJsonSchema = toGeminiJsonSchema(schema);
    for (let attempt = 0; attempt < MAX_ATTEMPTS; attempt++) {
      if (!limiter.tryAcquire()) {
        const seconds = Math.ceil(limiter.retryAfterMs() / 1000);
        throw new UserFacingError(`Slow down a little: try again in ${seconds} seconds.`);
      }
      const parsed = schema.safeParse(parseJson(await generate({ prompt, pdfBase64, responseJsonSchema })));
      if (parsed.success) return parsed.data;
    }
    throw new UserFacingError('The AI returned an unexpected answer. Please try again.');
  }

  return {
    extractClaims: async (pdfBase64, company) =>
      (await ask(extractionSchema, extractClaimsPrompt(company), pdfBase64)).claims,
    assess: (claim, turns, company) => ask(assessmentSchema, assessPrompt(claim, turns, company)),
    fixPlan: (claim, result, company) => ask(fixPlanSchema, fixPlanPrompt(claim, result, company)),
  };
}

function parseJson(raw: string): unknown {
  try {
    return JSON.parse(raw);
  } catch {
    return undefined;
  }
}
```

```ts
      },

    const result = await model.generateContent(parts);
    return result.response.text();
  };
```

```ts
import { UserFacingError } from './errors';

export const MAX_RESUME_BYTES = 10 * 1024 * 1024;

/** Returns a message for the student, or null when the file is an acceptable resume PDF. */
export function validateResumeFile(file: File | null): string | null {
  if (!file) return 'Choose your resume PDF first.';
  const isPdf = file.type === 'application/pdf' || file.name.toLowerCase().endsWith('.pdf');
  if (!isPdf) return 'Please upload a PDF file.';
  if (file.size === 0) return 'That file is empty.';
  if (file.size > MAX_RESUME_BYTES) return 'Please upload a PDF under 10 MB.';
  return null;
}

/** Reads the file, checks the PDF signature, and returns base64 for the model. */
export async function readPdfAsBase64(file: File): Promise<string> {
  const bytes = new Uint8Array(await file.arrayBuffer());
  if (String.fromCharCode(...bytes.subarray(0, 5)) !== '%PDF-') {
    throw new UserFacingError('That file is not a valid PDF.');
  }
  let binary = '';
  for (let i = 0; i < bytes.length; i += 0x8000) {
    binary += String.fromCharCode(...bytes.subarray(i, i + 0x8000));
  }
  return btoa(binary);
}
```

```ts
import { z } from 'zod';
import raw from './companies.json';

const list = z.array(z.string());

const companySchema = z.object({
  id: z.string().min(1),
  name: z.string().min(1),
  reports: z.number().int().nonnegative(),
  roles: list,
  rounds: z.array(z.object({ name: z.string(), format: z.string(), focus: list })),
  techTopics: list,
  sampleQuestions: list,
  hrQuestions: list,
  tips: list,
});

/** Anonymised interview profile distilled from past candidates' placement feedback. */
export type CompanyProfile = z.infer<typeof companySchema>;

/** Keeps only well-formed profiles, sorted by name. */
export function parseCompanies(data: unknown): CompanyProfile[] {
  if (!Array.isArray(data)) return [];
  return data
    .flatMap((item) => {
      const parsed = companySchema.safeParse(item);
      return parsed.success ? [parsed.data] : [];
    })
    .sort((a, b) => a.name.localeCompare(b.name));
}

export const companies = parseCompanies(raw);

export function findCompany(id: string): CompanyProfile | null {
  return companies.find((company) => company.id === id) ?? null;
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react';

interface SpeechResultList {
  length: number;
  [index: number]: { isFinal: boolean; 0: { transcript: string } };
}

interface Recognition {
  lang: string;
  continuous: boolean;
  interimResults: boolean;
  onresult: ((event: { resultIndex: number; results: SpeechResultList }) => void) | null;
  onend: (() => void) | null;
  onerror: (() => void) | null;
  start(): void;
  stop(): void;
}

type RecognitionConstructor = new () => Recognition;

function recognitionConstructor(): RecognitionConstructor | null {
  const w = window as unknown as { SpeechRecognition?: RecognitionConstructor; webkitSpeechRecognition?: RecognitionConstructor };
  return w.SpeechRecognition ?? w.webkitSpeechRecognition ?? null;
}

/** Browser speech-to-text (Indian English). `supported` is false where the Web Speech API is missing. */
export function useSpeechInput(onText: (text: string) => void) {
  const [listening, setListening] = useState(false);
  const recognition = useRef<Recognition | null>(null);
  const onTextRef = useRef(onText);

  useEffect(() => {
    onTextRef.current = onText;
  }, [onText]);

  useEffect(() => () => recognition.current?.stop(), []);

  const start = useCallback(() => {
    const Constructor = recognitionConstructor();
    if (!Constructor) return;
    const rec = new Constructor();
    rec.lang = 'en-IN';
    rec.continuous = true;
    rec.interimResults = false;
    rec.onresult = (event) => {
      for (let i = event.resultIndex; i < event.results.length; i++) {
        const result = event.results[i];
        if (result.isFinal) onTextRef.current(result[0].transcript.trim());
      }
    };
    rec.onend = () => setListening(false);
    rec.onerror = () => setListening(false);
    recognition.current = rec;
    rec.start();
    setListening(true);
  }, []);

  const stop = useCallback(() => recognition.current?.stop(), []);

  return { supported: recognitionConstructor() !== null, listening, start, stop };
}
```

```tsx
import { useEffect, useReducer, useState } from 'react';
import type { AiClient } from './ai/client';
import { HotSeat } from './components/HotSeat';
import { Results } from './components/Results';
import { StartScreen } from './components/StartScreen';
import { companies, findCompany } from './data/companies';
import { sessionReducer } from './domain/session';
import { clearSession, loadSession, saveSession } from './domain/storage';
import { friendlyError } from './lib/errors';
import { readPdfAsBase64 } from './lib/pdf';

interface AppProps {
  client: AiClient | null;
}

export default function App({ client }: AppProps) {
  const [state, dispatch] = useReducer(sessionReducer, undefined, () => loadSession());
  const [busy, setBusy] = useState(false);
  const [busyClaimId, setBusyClaimId] = useState<string | null>(null);
  const company = findCompany(state.companyId);
  const active = state.claims[state.activeIndex];

  useEffect(() => {
    saveSession(state);
  }, [state]);

  async function run(task: () => Promise<void>) {
    setBusy(true);
    try {
      await task();
    } catch (error) {
      dispatch({ type: 'failed', message: friendlyError(error) });
    } finally {
      setBusy(false);
    }
  }

  function handleStart(file: File, companyId: string) {
    if (!client) return;
    void run(async () => {
      dispatch({ type: 'extractStarted', companyId });
      const pdf = await readPdfAsBase64(file);
      dispatch({ type: 'claimsExtracted', claims: await client.extractClaims(pdf, findCompany(companyId)) });
    });
  }

  function handleAnswer(answer: string) {
    if (!client || !active) return;
    const turns = [...active.turns, { question: state.currentQuestion, answer }];
    void run(async () => {
      dispatch({ type: 'answerAssessed', answer, assessment: await client.assess(active.claim, turns, company) });
    });
  }

  function handleFixPlan(claimId: string) {
    const target = state.claims.find((c) => c.claim.id === claimId);
    if (!client || !target) return;
    setBusyClaimId(claimId);
    client
      .fixPlan(target.claim, target.result, company)
      .then((fixPlan) => dispatch({ type: 'fixPlanLoaded', claimId, fixPlan }))
      .catch((error: unknown) => dispatch({ type: 'failed', message: friendlyError(error) }))
      .finally(() => setBusyClaimId(null));
  }

  function handleRestart() {
    clearSession();
    dispatch({ type: 'reset' });
  }

  return (
    <div className="app">
      <header className="site-header">
        <h1>
          <span aria-hidden="true">🔥</span> HotSeat
        </h1>
        <p className="tagline">Can you defend your resume?</p>
      </header>
      <main>
        {!client && <SetupNotice />}
        {client && (state.phase === 'start' || state.phase === 'extracting') && (
          <StartScreen companies={companies} busy={state.phase === 'extracting'} error={state.error} onStart={handleStart} />
        )}
        {client && state.phase === 'interview' && active && (
          <HotSeat
            key={`${active.claim.id}-${active.turns.length}`}
            active={active}
            position={state.activeIndex + 1}
            total={state.claims.length}
            question={state.currentQuestion}
            busy={busy}
            error={state.error}
            onAnswer={handleAnswer}
            onFinish={() => dispatch({ type: 'finishNow' })}
          />
        )}
        {client && state.phase === 'results' && (
          <Results
            claims={state.claims}
            companyName={company?.name ?? 'General'}
            busyClaimId={busyClaimId}
            error={state.error}
            onRedefend={(claimId) => dispatch({ type: 'redefendStarted', claimId })}
            onFixPlan={handleFixPlan}
            onRestart={handleRestart}
          />
        )}
      </main>
      <footer className="site-footer">
        <p>Company insights distilled from past candidates' placement feedback, anonymised. Powered by Gemini via Firebase AI Logic.</p>
        <button type="button" className="link" onClick={handleRestart}>
          Clear my data
        </button>
      </footer>
    </div>
  );
}

function SetupNotice() {
  return (
    <section className="card" role="alert">
      <h2>Setup needed</h2>
      <p>
        Firebase is not configured. Copy <code>.env.example</code> to <code>.env.local</code>, add your Firebase web app
        settings, and restart the dev server.
      </p>
    </section>
  );
}
```
